Middleware install (outlet PC)
1) Copy the published folder to the outlet PC (e.g., installation/).
2) Edit appsettings.json in the config folder with POS DB, Outlet ID, Supabase URL/Key.
3) Open PowerShell as Administrator.
4) Run the installer script from the folder:
   pwsh -File .\scripts\install-service.ps1 -PublishOutput . -InstallPath "C:\Program Files\UltraAutomaticScreenSaver" -ConfigRoot "%LOCALAPPDATA%\Ultra Automatic Screen Saver"
5) Start the service (if not started) from Services or PowerShell.
6) Confirm it is running and syncing (service status/logs).

Outlet warehouse stocktake procedure
1) In Afterten Orders app: Home → Outlet Stocktake.
2) Start period (opening counts seed from previous closing when available).
3) Enter opening counts and save.
4) During the day: receive orders (Receive Orders), record transfers/damages; POS middleware syncs sales into stock_ledger.
5) At closing: enter closing counts in the app, then Close period.
6) Closing auto-calculates variance in backoffice (/Warehouse_Backoffice/stocktakes) and opens the next period with opening = previous closing.
7) POS sync opening/cutoff counters update automatically on period open/close (migration 20260616210000).

Backoffice monitoring
- Live balance: /Warehouse_Backoffice/stocktakes (polls ledger every 30s).
- Closed periods: PDF variance button per period.
- Formula: Expected = Opening + Transfers + Damages − Sales; Variance = Expected − Closing.

See docs/outlet-stocktake-variance.md for schema and API details.
