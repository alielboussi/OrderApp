# Legacy Kotlin Android apps (removed)

The **Afterten Orders**, **stocktake-app**, **supervisor-app**, and **Shared** Kotlin modules were removed on 2026-08-03.

They targeted Supabase and are replaced by:

- **Outlet orders:** `afterten-orders-expo/` (Expo + Firebase Auth + Firestore + Cloud Functions)
- **Warehouse backoffice:** `afterten-website-portal/`

Historical docs that mention the Kotlin apps (`docs/stocktake-portal-system.md`, `docs/outlet-stocktake-variance.md`, etc.) describe the old architecture and are kept for reference only.
