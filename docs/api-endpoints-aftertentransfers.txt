Afterten Transfers App — API endpoints
Base URL: https://aftertentransfers.app

Generated from Scanners/src/app/api (Next.js App Router).
All paths are relative to the base URL unless noted.

================================================================================
MIDDLEWARE & POS SALES
================================================================================

GET  https://aftertentransfers.app/api/middleware-status
     Middleware heartbeat + catalog sync status for POS outlets.

GET  https://aftertentransfers.app/api/middleware-catalog-schedule
PUT  https://aftertentransfers.app/api/middleware-catalog-schedule
     Scheduled POS catalog sync settings.

GET  https://aftertentransfers.app/api/outlet-middleware-sales
     POS sales by outlet (not warehouse). Query: outletId (Till 1 / Till 2 separately), since, until, limit.
     Response includes outlet_uuid per sale and outlet_summaries when multiple outlets match.

GET  https://aftertentransfers.app/api/pos-sales
     POS orders/sales from Supabase (query: outletId, since, until, branchId, includeSales).

GET  https://aftertentransfers.app/api/pos-sync-alert
     POS sync alert / health check.

POST https://aftertentransfers.app/api/catalog/sync-pos-catalog
     Push catalog/menu groups to POS middleware.

POST https://aftertentransfers.app/api/catalog/request-pos-catalog-sync
     Queue catalog sync event for an outlet.

POST https://aftertentransfers.app/api/catalog/cancel-offline-pending-sync
     Cancel pending offline catalog sync events.

NOTES
================================================================================

- Middleware service on outlet PCs calls Supabase RPC directly; it does not use these Next.js routes except where backoffice triggers sync.
- External stock API (purchase import source) is separate:
  https://afterten-stock-api-896827614552.us-central1.run.app/stock/movements?type=receive
- Auth: most backoffice APIs expect a logged-in Supabase session; some import routes use server env tokens.
